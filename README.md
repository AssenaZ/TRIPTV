# TRIPTV

Playlist IPTV de chaînes de télévision turques au format M3U, compatible avec les lecteurs prenant en charge les playlists par URL, notamment IBO Player et VLC.

## Playlist

- **URL (après activation) :** https://assenaz.github.io/TRIPTV/tr.m3u

## Utilisation

Copiez l'URL de la playlist et ajoutez-la dans votre lecteur IPTV compatible M3U.

## Contenu

Cette playlist contient **86 entrées de chaînes turques**, avec les métadonnées et catégories disponibles.

## Disponibilité des flux

Les URL des flux peuvent changer ou être indisponibles selon le réseau, la région ou les restrictions des diffuseurs. Leur présence dans la playlist ne garantit pas leur fonctionnement. Ce dépôt n'héberge pas les flux vidéo. Respectez les droits de diffusion applicables.
